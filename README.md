# Яндекс.Афиша: исследовательский анализ данных

## Summary (EN)

Exploratory analysis of Yandex.Afisha ticket orders (June–October 2024): cleaning, seasonality, regional and operator breakdowns, and two hypotheses about mobile vs desktop users with effect-size estimates. Python, pandas, matplotlib, SciPy.


Учебный проект по анализу заказов билетов сервиса Яндекс.Афиша за период с 1 июня по 31 октября 2024 года: динамика спроса, структура афиши, регионы, билетные операторы и площадки, а также проверка двух гипотез о поведении пользователей мобильных и десктопных устройств.

**Автор:** Карташов Владимир

## Что внутри

- `yandex_afisha_eda.ipynb` — ноутбук с полным анализом: загрузка и очистка данных, исследовательский анализ, проверка гипотез, выводы и рекомендации.
- `requirements.txt` — зависимости.

Данные не хранятся в репозитории: ноутбук читает их по публичным ссылкам Яндекса.

## Ключевые результаты

- После очистки (возвраты, выбросы, аномальные выгрузки) в анализ вошло 274 775 заказов на 146.7 млн ₽.
- Спрос растёт каждый месяц: 33 974 заказа в июне, 44 585 в августе, 65 759 в сентябре (+47.5 %), 90 045 в октябре (+36.9 %). В среднем за день — с 1 132 до 2 905 заказов.
- Структура афиши смещается к театру: 20.1 % → 27.3 % заказов и 21.1 % → 25.7 % выручки. Концерты остаются лидером (42.5 % → 38.3 % заказов), спорт растёт с 2.5 % до 6.8 %.
- Средняя цена билета осенью падает: концерты −7.3 % (299 → 277 ₽), театр −16.6 % (212 → 177 ₽), ёлки −16.9 %. Растут спорт (+17.3 %), стендап (+6.1 %), выставки (+4.5 %).
- Лидер по заказам — пятница (24 837), затем четверг и среда; минимум в воскресенье. Выходные дают 26.2 % заказов.
- 81 % заказов — с мобильных устройств, доля не зависит от сезона.
- Топ-5 регионов: Каменевский регион (24.7 % мероприятий и 28.1 % заказов), Североярская, Широковская области, Светополянский округ, Речиновская область. По выручке среди операторов лидирует «Билеты без проблем» (15.4 %).
- Гипотеза 1 (мобильные делают больше заказов) подтверждается со слабым эффектом: медианы 2 и 2, дельта Клиффа 0.06–0.13.
- Гипотеза 2 (у мобильных больше интервал между заказами) подтверждается со слабым эффектом: медианный интервал 2.5 дня против 0, средние 10.1 и 8.3 дня, дельта Клиффа 0.17.

## Методические решения

- **Валюта.** `curs` — рублей за 100 тенге, поэтому выручка приводится как `revenue × curs / nominal`. В первой версии анализа формула была перевёрнута, из-за чего тенге давали 47 % выручки вместо 3 %.
- **Аномальные выгрузки.** Часы, где число заказов более чем в 8 раз выше медианы для этого часа (3 сентября, 1 октября, 15 октября, 31 октября), исключены: это выгрузки партнёров, а не реальный спрос.
- **Возрастной рейтинг.** `age_limit` — рейтинг мероприятия (0+, 6+, 12+, 16+, 18+), а не возраст покупателя.
- **Цена билета.** Считается как сумма выручки, делённая на число билетов (взвешенная цена), а не как среднее из отношений.
- **Гипотезы.** Используется односторонний тест Манна—Уитни и дельта Клиффа как размер эффекта: при десятках тысяч наблюдений p-value сам по себе не показателен.

## Ограничения

- В данных есть сверхактивные `user_id` (до 9 881 заказа); топ-100 пользователей дают 41.7 % заказов при медиане 2. Это искажает метрики «на пользователя».
- Заказы дробятся: до 105 записей одного пользователя по одному событию в один день, поэтому «заказ» не всегда равен «покупке».
- `total` и `revenue` различаются в 269 060 строках из 274 775; смысл `total` в описании данных не раскрыт, в анализе используется `revenue`.
- `organizers` обезличены (`№4893`), рейтинг организаторов по названиям невозможен.
- Названия регионов и площадок выглядят синтетическими: выводы по географии стоит воспринимать как учебные.
